# utools-plugin-image-snapshot-tools

基于 [uTools](https://www.u-tools.cn/) 的截图工具插件：截图后提供 **贴图 / 框图 / 复制 / 另存为** 快捷操作，并把每次截图自动保存到本地历史目录，支持历史列表、全屏查看和按天自动清理。

## 功能

- **截图**：在 uTools 中搜索「截图」进入插件，自动调起系统截图框选
- **截图历史**：搜索「截图历史」直接打开历史列表页，不触发截图——适合 OCR 识别期间切走后回来查看结果
- **自动保存**：每次截图自动保存为 PNG 到 `用户图片目录\截图历史\`（文件名形如 `截图_20260916_161234.png`），无需手动操作
- **🕘 历史列表**：顶部「历史记录」按钮或取消截图时进入列表页，缩略图按日期（yyyy-MM-dd）分组、时间倒序展示所有历史截图
- **全屏查看**：点击列表中的图片全屏展示，支持滚轮缩放、拖拽平移，并可复制 / 贴图 / 打开所在文件夹 / 删除
- **自动清理**：可设置截图保留天数（默认 30 天，0 表示永久保留），启动时和每次截图后自动清理过期文件，也可点「立即清理」手动执行
- **📌 贴图**：把截图固定在屏幕最上层（支持多张贴图，自动错开排列）——拖拽移动、滚轮缩放、悬浮 ✕ / 右键 / Esc 关闭
- **⬜ 框图**：在截图上拖拽绘制矩形框线标注，支持 6 种颜色、撤销、清空；贴图/复制/另存为时自动合成框线
- **📋 复制**：将图片（含框图标注）写入剪贴板，可直接粘贴到 Word、聊天窗口等
- **🔤 OCR 文字识别**：调用 AI 大模型（视觉/多模态模型）识别截图中的文字，表格自动输出为 Markdown 表格，标点、标题、列表等按 Markdown 保留，结果可一键复制
- **💾 另存为**：弹出系统保存对话框，把图片另存到任意位置（PNG/JPG，选 JPG 时自动转换）

## 开发调试

1. 安装 [uTools](https://www.u-tools.cn/) 及「uTools 开发者工具」插件
2. 打开 uTools 开发者工具 → 新建项目 → 手动创建 → 项目目录选择本仓库目录 → 确定
3. 在应用开发界面选中 `plugin.json` → 接入开发 → 打开
4. 修改代码后建议在开发者工具设置中开启「退出到后台立即结束运行」，重新进入插件即加载最新代码（`preload.js` 的修改必须开启该选项才会生效）

## OCR 接口配置

OCR 通过 **OpenAI 兼容的多模态接口**（支持图片输入的视觉模型）实现，在「⚙ 设置」页填写配置并保存（保存在 `config.json` 中，仅本地使用）：

| 项 | 示例 |
| --- | --- |
| API 地址 | 通义千问 `https://dashscope.aliyuncs.com/compatible-mode/v1`、Kimi（Moonshot）`https://api.moonshot.cn/v1`、OpenAI `https://api.openai.com/v1` |
| API Key | 各平台申请的密钥 |
| 模型 | 需为视觉模型，如 `qwen-vl-plus`、`qwen3-vl-plus`、`moonshot-v1-8k-vision-preview`、`gpt-4o` |

点击「🔤 OCR」后图片会先缩小到最长边 1600px 再发送，识别结果以 Markdown 文本展示，可通过「复制识别结果」拷贝。

## 项目结构

| `plugin.json` | 插件配置：指令、单例模式、窗口高度 |
| `preload.js` | 指令注册、贴图窗口管理、截图历史服务（自动保存/列表/删除/清理/设置） |

| `scripts/gen-logo.js` | logo 生成脚本（`node scripts/gen-logo.js`） |

## 数据说明

- 历史截图存放于 `用户图片目录\截图历史\`，按日期 `yyyy-MM-dd` 子目录整理，设置保存在根目录的 `config.json`
- 老版本散落在根目录的截图会自动迁移到对应日期子目录；日期目录清空后自动删除
- 清理规则：按文件修改时间计算，超过保留天数即删除；设置为 0 时永不自动清理
- 手动「另存为」的文件不受自动清理影响

## 已知行为说明

- 每次通过「截图」关键词进入插件都会直接开始一次全新的截图，不展示上一次的截图；取消截图则进入历史列表
- OCR 识别进行中或有未查看的识别结果时，重新唤起插件不会自动截图，而是恢复识别现场；此时可点「重新截图」或用「截图历史」指令
- 通过「截图历史」指令进入只打开列表页，绝不触发截图
- 贴图窗口随插件进程存活：在 uTools 中关闭插件窗口只是隐藏到后台，贴图不受影响；若开启了「退出到后台立即结束运行」，退出插件时贴图会一并关闭
- 贴图初始大小不超过主屏工作区的 85%，以鼠标所在位置为中心出现，多张自动错开
